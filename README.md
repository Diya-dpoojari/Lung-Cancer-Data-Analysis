\# Lung Cancer Data Analysis



This project focuses on analyzing a lung cancer dataset using Python and basic data analysis techniques.



\## Tools Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Jupyter Notebook



\## Analysis Performed



\- Data inspection and understanding

\- Identification of numerical and categorical data

\- Missing value analysis

\- Duplicate record detection and removal

\- Statistical analysis

\- Outlier detection using the IQR method

\- Data visualization using Matplotlib



\## Dataset



The dataset contains information related to lung cancer, including age, gender, smoking, symptoms, and lung cancer status.



\## Project Objective



The objective of this project is to explore and analyze the dataset using Python and understand the patterns and characteristics present in the data.
